# Programación Básica - Funciones con parámetros y retorno

## Problema

Calcular el precio total de una compra a partir del precio de un producto y la cantidad comprada.

## Requisitos utilizados

- Función: `calcular_total`

- Parámetros: `precio` y `cantidad`

- Retorno: `return total`

- Llamada a la función: `calcular_total(precio_producto, cantidad_productos)`

- Resultado mostrado en pantalla con `print`

## Ejemplo de ejecución

Precio del producto: 12.50

Cantidad: 3

Resultado: 37.5# ejercicio_funciones.py
